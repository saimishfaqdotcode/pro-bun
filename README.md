# PRO BUN

A modern, responsive burger restaurant website built with HTML, Tailwind CSS, and JavaScript.

## Live Website

**[Visit PRO BUN](https://pro-bun.vercel.app/)**

## Repository

**[View Source Code on GitHub](https://github.com/saimishfaqdotcode/pro-bun)**

## About The Project

PRO BUN is a modern burger restaurant website designed to provide a clean and engaging online food-ordering experience.

The project includes a responsive restaurant interface with menu browsing, product details, cart management, checkout, search functionality, and order confirmation.

The website was built with a focus on:

- Responsive design
- Clean and modern UI
- User-friendly navigation
- Product browsing
- Shopping cart functionality
- Simple checkout flow
- Mobile-friendly usability

## Features

### Home Page

- Hero section
- Brand introduction
- Featured products
- Food categories
- Promotional sections
- Call-to-action sections
- Responsive layout

### Menu

- Complete product listing
- Product categories
- Product cards
- Responsive grid layout
- Product navigation

### Product Details

- Product image
- Product name
- Product description
- Product price
- Add-to-cart functionality

### Shopping Cart

- Add products to cart
- Increase and decrease quantities
- Remove products

- Cart synchronization

### Checkout

- Customer information
- Order summary

- Order confirmation flow

### Search

- Product search
- Dynamic product filtering
- Responsive search interface

The website is designed to work across:

- Desktop screens
